# Security

ChemFox is a desktop app that works offline. The only network request it makes is the optional update check,
which asks GitHub for the list of releases (see "Privacy" in the README).

## Reporting a problem

If you find a security problem (for example, a document file that crashes ChemFox in a way that could run
code, or anything about the installers), please report it **privately** through GitHub:
**Security → Report a vulnerability** on this repository. Don't open a public issue.

Include the ChemFox version (Help → About), your operating system, and steps or a file that shows the problem.
I'll look at reports as soon as I reasonably can; there's no formal response time.

## Supported versions

Only the newest release gets fixes.
